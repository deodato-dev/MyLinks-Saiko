## 🎯 Sobre o Projeto

O **MyLinks** é um projeto pessoal desenvolvido para estudos de **HTML e CSS**. Ele funciona como uma página centralizada onde visitantes podem encontrar todos os links importantes em um só lugar, com um design limpo e interativo.

### ✨ Funcionalidades

- ✅ Design responsivo (funciona em mobile, tablet e desktop)
- ✅ Animações suaves em hover e clique
- ✅ Fontes personalizadas para identidade visual única
- ✅ Ícones das redes sociais integrados (Font Awesome)
- ✅ Cores e temas pensados para acessibilidade
- ✅ Efeitos 3D nos botões com sombras e translação

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| **HTML5** | Estrutura semântica da página |
| **CSS3** | Estilização, animações e responsividade |
| **Font Awesome** | Ícones das redes sociais |
| **Vercel** | Hospedagem e deploy contínuo |

## 📱 Responsividade

O projeto se adapta automaticamente a diferentes tamanhos de tela:

- **Desktop:** Layout completo com efeitos visuais
- **Tablet:** Ajuste no tamanho dos elementos
- **Mobile:** Layout otimizado com fonte e padding menores
